# Welcome to My Printf
***

## Task
The goal of this project is to
recreate the standard printf
function from the C library.

The function must handle several
format specifiers and return the
number of printed characters.

## Description
My_Printf is a reimplementation
of the standard printf function
from the C standard library.

This project focuses on learning
about variadic functions and the
management of formatted output.

## Installation
Clone the repository and compile
the project using the command:
make
To remove object files use:
make clean
To remove all generated files use:
make fclean
To rebuild the project completely:
make re

## Usage
Include the header file in your
source code before compilation:
#include "ft_printf.h"

Example of use:
ft_printf("Hello %s\n", "World");
The function prints formatted
output and returns the number
of characters written.
